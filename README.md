# 한방승부 · 랜덤 내기 21종

오늘 커피 쏠 사람을 한 방으로 정하는 미니게임 모음 (단일 HTML 파일).

- 📱 **싱글모드** — 폰 1대를 돌려가며 21종 게임 + 1등 탈출 릴레이
- 🌐 **멀티모드** — 최대 8명이 각자 폰으로 동시에 플레이, 결과 자동 조합 (MQTT over WSS)

## 멀티모드 사용법
1. 한 명이 **방 만들기** → 4자리 코드가 만들어집니다.
2. 친구는 **초대 링크**(`https://xoghksl9978.github.io/Hanbang/?room=XXXX`)를 열고 이름만 입력해 입장.
3. 방장이 당첨 인원(K)과 게임(21종 또는 랜덤)을 고르고 **게임 시작!**
4. 모두 끝나면 순위가 합쳐져 1등은 커피 면제, 꼴찌 K명은 "💸 한방 쏴~!"

통신: `wss://broker.emqx.io:8084/mqtt` → 실패 시 `wss://broker.hivemq.com:8884/mqtt`.
